👤 我的 · 使用说明

这个工作台只管一件事：把「有明确终点的目标」拆成今天能动手的量，并且让你每天都比昨天更会做事。

💾 数据管理

所有数据都存在你自己的浏览器里，不联网、不上传。可以随时备份、恢复或清空。
📤
导出 JSON 备份
把目标、子任务、打卡记录、障碍记录、日 / 周 / 月 / 年复盘全部导出为一个 JSON 文件，方便存档或换设备。
📥
导入 JSON 恢复
从之前导出的 JSON 文件恢复全部数据。导入会覆盖当前所有数据，建议先导出当前备份。
🗑️
清空全部数据
删除本机保存的所有目标、复盘、障碍与打卡记录。此操作不可撤销，请先导出备份。

🎯 个人目标：把大目标拆成今天能干的量

适用于“在年底完成 FFM 温循老化装备导入制造”“读完各子系统设计文档”这类有终点的目标，不是喝水打卡。
1
新建目标：在「个人目标」页签点右上角「＋ 新建目标」，填名称、分类、单位、总量、起止日期和配色。
2
分类筛选：目标分为工作达成、学习提升、人际交往、身体健康、小孩教育、父母关怀、夫妻关系等。顶部点分类标签就能只看这一类。
3
写障碍与对策：每个目标和子任务都能填「达成目标或任务，我将会遇到哪些可能的障碍 / 困难？」和「如果遇到，你该如何解决」。填完可以在卡片上直接改或删。
4
拆子任务：大目标下面点「＋ 添加子任务」，把“读完设计文档”拆成“读完温控子系统文档”这种一次能完成的动作。打卡记在子任务上，进度自动汇总到目标。
5
每日打卡：系统自动算出今日建议量 = 剩余量 ÷ 剩余天数，打卡框里已经预填好，你可以改成实际完成的量。
6
修改打卡记录：点目标或子任务卡片上的「📋 记录」按钮，可以查看所有打卡记录，每条都带记录时间，支持直接编辑完成量、日期、备注，或删除某条记录。
7
看三个数字：完成率、连续打卡天数、预计完成日。预计完成日按近 7 天平均速度推算，并和截止日比较，显示“提前 N 天”或“拖后 N 天”；样本不足 2 天时显示“暂无推算”，不编数字。
💡 目标总量要能数得清，比如“20 个子系统文档”“8 台设备”。数不清的量，就算不出今日建议量。

📝 日复盘 · KISS 复盘法

每天收工前花 5 分钟，用四格法快速回看今天。
K
Keep 保持：列出 1-3 个做得好的事情，分析好在哪里，如何保持。
I
Improve 改进：列出 1-3 个需要改进的事情，后续将采取哪些行动来改进。
S
Stop 停止：列出 1-3 个没必要做的事情，下次不再做。
S
Start 开始：列出 1-3 个想做却没做，但接下来准备做的事情。
📅
打卡按钮：日复盘页签右上角的「📅 打卡」按钮，一键打卡今天所有还有剩余量的目标 / 子任务。
⏰
补录最近 7 天：日期旁边的胶囊按钮可以切换到今天、昨天、2 天前……一直到 6 天前。带 ✓ 的表示那天已经写过了。
💡 顶部提醒只出现在「日复盘」页签，提醒你今天还没写。

📅 周复盘 · PDCA 复盘法

以自然周（周一到周日）为单位，用 PDCA 回看这一周。
P
Plan 计划：制定计划，写下本周计划，计划做哪些事。
D
Do 执行：实施、执行，写下具体完成了哪些事。
C
Check 检查：核对计划中哪些事没有完成，分析原因。
A
Action 处理：针对没有完成的计划，后续有什么改善的措施。

🗓️ 月复盘 · GRAI 复盘法

以自然月为单位，用 GRAI 四步做阶段回看。
G
Goal 回顾目标：当初的目标是什么？核心阶段性目标是什么？
R
Result 评估结果：目标是否完成？结果和目标差距多少？和原定目标相比有哪些优势和劣势？
A
Analysis 分析原因：整个过程经历了什么？结果怎么样？产生该结果的原因有哪些？
I
Insight 归类总结：分析得出的对应措施是什么？得到的经验是什么？

🎊 年复盘 · KPT 复盘法

以自然年为单位，用 KPT 三问做全年回看。
K
Keep 保持：哪些行为是可以保持的？
P
Problem 问题：曾遇到了哪些问题？
T
Try 尝试：可以尝试去做什么？
📌
复盘方向参考：内在（个人成长、职业发展、财务状况）；外在（朋友、娱乐休闲、家庭、健康）。

📊 进度看板：一眼看清哪些目标卡住了

看板把目标和子任务按「未开始 / 进行中 / 已完成」三列摊开，进度一眼可辨。
·
目标看板：每张卡片是一个目标，显示分类、完成率、截止日、今日建议量。
·
子任务看板：切换后每张卡片是一个子任务，方便聚焦到具体动作上。
·
点卡片跳转：点击卡片会跳到「个人目标」页签并高亮对应目标，方便快速修改。
💡 每周看一眼看板：如果「进行中」一列长期不动，说明卡点需要处理了。

💾 数据说明

·
所有数据只保存在你自己的浏览器里（localStorage），不联网、不上传、不需要账号。
·
换电脑、换浏览器、清理浏览器数据都会导致内容丢失。重要内容请定期使用「导出 JSON 备份」。
·
把网页另存为文件保存在本地，双击就能打开使用。
